# PDFreds — versiones

Aquí se publican los **instaladores de PDFreds** para Windows y el archivo `latest.json` que usan las copias
instaladas para actualizarse solas. El código fuente de la aplicación es privado.

- Descarga la última versión en [Releases](https://github.com/rojasabe/pdfrojas-studio-releases/releases/latest).
- Los instaladores van firmados: PDFreds solo acepta actualizaciones firmadas con la llave de su autor.

PDFreds es un visor y editor de PDF que funciona sin conexión: ningún archivo sale de tu computadora.
